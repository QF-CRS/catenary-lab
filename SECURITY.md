# Security policy

## Supported versions

Only the latest version on the default branch is currently supported.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Contact the
maintainer privately through the email address listed on the repository profile
and include a reproducible description, affected version, and suggested
mitigation when available.

This project does not execute uploaded code or access external systems, but
reports about unsafe parsing, dependency problems, or supply-chain concerns are
still welcome.
